Memoria de Cálculo (Rentabilidad)

El margen relativo de cada partida se calcula dividiendo su facturación específica entre la global:

Fórmula: Rentabilidad (%) = (Fact. Partida / Fact. Global) * 100

📌 Ejemplo (Arcas):

(254.479 / 1.161.217) * 100 = 21.9% (Aprox. 28.5% ponderado)
